\# Datos del proyecto



Fuente:

https://www.kaggle.com/datasets/neuralsorcerer/student-performance



El dataset es sintetico.



Los archivos originales no se incluyen en GitHub por su tamaño.

Para reproducir el procesamiento, descargarlos y ubicarlos asi:



data/train.csv

data/validation.csv

data/test.csv



La preparacion de muestras se realiza desde la raiz con:



python -m src.prepare\_math\_samples



El dashboard no necesita los originales para clasificar nuevos CSV.

Requiere el modelo final y los reportes incluidos en el repositorio.



Los archivos de demostracion no representan estudiantes reales.
